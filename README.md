# NAVER / Kakao Ad Template Studio

Alibaba.com 한국 디스플레이 광고(NAVER Native · Kakao Display) 소재 제작용 웹 스튜디오입니다.
한국어 / 중국어 전환을 지원하며, 구좌별 제작 가이드를 상단에 고정해 보여줍니다.

## 바로 보기

https://yerinkkim.github.io/naver-kakao-ad-template-studio/

## 포함 구좌 (05~12)

| No. | 구좌 | 사이즈 |
| --- | --- | --- |
| 05 | NAVER Native Square | 1200 x 1200 |
| 06 | NAVER Native Portrait | 1200 x 1800 |
| 07 | NAVER Native Wide | 1200 x 628 |
| 08 | NAVER Native Thumbnail | 342 x 228 |
| 09 | Kakao Display Square | 500 x 500 |
| 10 | Kakao Display Story | 720 x 1280 |
| 11 | Kakao Display Vertical | 800 x 1000 |
| 12 | Kakao Display Wide | 1200 x 600 |

## 규정 반영 사항

- Kakao Display 800x1000 · 1200x600: 이미지 내 텍스트 48~164px
- Kakao Display Wide 1200x600: 텍스트 최대 3줄, 텍스트 컬러 3종 이하
- 세이프존: Story 상하 89 / 좌우 47, Vertical 상하 100 / 좌 40, Wide 상하 89~90 / 좌우 47
- NAVER Native 4개 구좌는 가이드 상 세이프존 · 이미지 내 텍스트 제한 규정 없음 (Thumbnail 은 썸네일 이미지 형태만 명시)
- 이미지 우측 하단은 UI 광고 요소에 가려질 수 있어 주요 요소 배치 비권장

## 사용 방법

단일 HTML 파일이므로 별도 빌드나 설치가 필요 없습니다.
`index.html` 을 브라우저로 열거나 위 링크로 접속하면 바로 사용할 수 있습니다.
